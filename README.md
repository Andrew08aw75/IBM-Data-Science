# IBM Data Science Professional Certificate – Portfolio

## Overview

This repository contains programming assignments, practical exercises, and data science projects developed throughout the **IBM Data Science Professional Certificate**.

The repository showcases the application of data science methodologies and technical skills across multiple areas, including Python programming, SQL, data visualization, machine learning, and exploratory data analysis.

It provides a collection of hands-on exercises and projects demonstrating the use of programming tools and analytical techniques to extract insights from data and solve practical problems.

## Repository Contents

The repository is organized into the following directories:

### 1. DataVisualization

Practical exercises and projects focused on data visualization, interactive dashboards, and graphical data exploration.

**Topics and tools include:**
- Data Visualization.
- Plotly.
- Interactive Visualizations.
- Dash Applications.
- HTML Components.
- Exploratory Data Analysis.
- Flight Delay Data Analysis.

### 2. ML – Machine Learning

Exercises and practical implementations focused on machine learning concepts and predictive modeling.

This section contains learning materials and programming assignments related to machine learning techniques.

### 3. Python

Python programming exercises and practical assignments covering fundamental programming concepts and data manipulation.

**Topics include:**
- Python Fundamentals.
- Data Structures.
- Dictionaries.
- Arrays and Data Manipulation.
- Programming Logic.

### 4. PythonProject

A collection of practical Python programming projects developed throughout the certification program.

This section showcases the application of Python programming skills to data-oriented problems.

### 5. SQL

SQL exercises, practical assignments, and supporting learning materials focused on relational databases and database operations.

**Topics include:**
- SQL Queries.
- SELECT Statements.
- Filtering and Sorting.
- Aggregate Functions.
- SQL Joins.
- Data Manipulation (INSERT, UPDATE, DELETE).
- Database Management.
- Transactions.
- Stored Procedures.
- Advanced SQL Techniques.
